Puzzle Generator — motivated by gerrymandle

Jun 2026

Bitmask-based exhaustive search algorithm to partition a hex grid into connected districts, using recursive backtracking with branch-and-bound pruning. Built a randomized generate-and-test search that samples board layouts and colorings, then re-verifies each candidate for solution uniqueness. This is my attempt at a HTML/SVG renderer in Python to turn my puzzle data into an interactive site.
